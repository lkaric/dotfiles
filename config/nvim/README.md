# nvim

LazyVim starter (https://github.com/LazyVim/starter), tracked here and
symlinked to `~/.config/nvim` out-of-store, so every edit is live.

- `lua/config/*.lua`: options, keymaps, autocmds, lazy bootstrap
- `lua/plugins/*.lua`: your plugin specs / overrides
- `lazy-lock.json`: pinned plugin versions, commit it after `:Lazy update`
